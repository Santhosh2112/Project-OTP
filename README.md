## Projection Description
A reusable OTP input component built with React, featuring controlled inputs, auto-navigation between fields, validation handling, and optimized state management.

## Features

- Auto move to next input
- Backspace support
- Numeric validation
- Responsive design
- Clean and minimal UI

## Tech stack

- React
- CSS

## How to Run

1. Clone the repository
2. Run `npm install`
3. Run `npm start`
